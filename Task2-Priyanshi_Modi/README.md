# Task 2 – Basic Encryption & Decryption

## 📌 Overview
This project is part of the DecodeLabs Cyber Security Internship (Batch 2026).  
**Task 2** focuses on implementing a **Basic Encryption & Decryption system** using the **Caesar Cipher**.  
The goal is to understand the fundamentals of **data confidentiality** and how information can be protected in transit through mathematical transformation.

---

## 🎯 Project Goal
Create a program that:
- Encrypts user text using a simple logic (Caesar Cipher or similar).
- Decrypts the encrypted text back to plaintext.
- Displays both encrypted and decrypted outputs in the terminal.
