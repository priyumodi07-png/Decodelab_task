# Task 1 – Password Strength Checker

## 📌 Overview
This project is part of the DecodeLabs Cyber Security Internship (Batch 2026).  
**Task 1** focuses on building a **Password Strength Checker** that evaluates whether a password is **Weak, Medium, or Strong** based on length, character variety, and entropy principles.

---

## 🎯 Project Goal
Create a program that:
- Checks password length.
- Validates use of numbers, symbols, and uppercase letters.
- Displays the password strength result.
